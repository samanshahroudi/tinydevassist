# TinyDevAssist

CPU Gradio demo for a small developer-support adapter. Answers can be inaccurate;
review suggested commands before using them. The project and measured experiment
are documented at the source repository. The Space needs an `HF_MODEL_REPO`
variable pointing to the published adapter repository.
